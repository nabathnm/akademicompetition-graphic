# Mockup Components (Layer 2)

High-fidelity device frames and simulated software surfaces for showcasing digital product experiences.

## Planned Components
- `PhoneFrame`: Modern smartphone mockup (iOS/Android bezel) with perspective tilt.
- `BrowserFrame`: Clean glass/dark minimal browser window.
- `AppInterface`: In-app feed, booking flow, or map interface container.
- `FloatingCard`: Elevated perspective card with realistic soft drop shadow.

## Conventions
- Device frames accept dynamic `children` to render live React UI inside the screens.
- Supports 3D rotation / isometric tilt parameters.
