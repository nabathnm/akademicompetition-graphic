# Scene Layouts (Layer 3)

Spatial compositions and grid frameworks for arranging multiple components within a scene.

## Planned Layouts
- `SplitScreenLayout`: Two-column layout (e.g. left copy, right device mockup).
- `CenteredHeroLayout`: Centered high-impact statement with supporting CTA or badges.
- `MetricShowcaseLayout`: Multi-card grid highlighting statistical achievements.
- `FeatureGalleryLayout`: Alternating showcase rows with animated highlights.
