# Motion System Documentation (Phase 2)

A comprehensive guide to the centralized animation logic, utilities, and custom hooks powering the Remotion Motion Graphics Framework.

---

## 1. Frame-Based Animation Principles

Every motion transformation in this framework adheres to deterministic frame-based execution:

1. **Deterministic Calculations**:
   - Every animated property at frame \(N\) must evaluate to the exact same value every time.
   - We strictly avoid `setTimeout`, `setInterval`, `requestAnimationFrame`, or CSS transitions/keyframes.
2. **Native Remotion Foundation**:
   - Direct integration with Remotion's `useCurrentFrame()`, `useVideoConfig()`, `interpolate()`, `spring()`, and `Easing`.
3. **Decoupled Architecture**:
   - Animation mathematics are isolated from visual and DOM rendering logic.
   - Future visual components (Layer 2) and scenes (Layer 3) consume pure numeric values and progress flags generated by this layer.

## 2. Animation Utilities (`src/utils/animation/`)

### A. Interpolation Utilities (`interpolate.ts`)

#### `interpolateValue(options)`
General-purpose interpolation helper supporting 2-point and multi-point ranges, easing curves, and extrapolation bounds.

```ts
import { interpolateValue } from '../utils/animation';

const opacity = interpolateValue({
  frame: currentFrame,
  inputRange: [0, 15, 30],
  outputRange: [0, 1, 0.5],
  easing: 'easeOutCubic',
  extrapolateLeft: 'clamp',
  extrapolateRight: 'clamp',
});
```

- **Parameters**:
  - `frame: number`: Current frame.
  - `inputRange: number[]`: Array of monotonic input frame numbers.
  - `outputRange: number[]`: Array of target values matching `inputRange`.
  - `easing?: EasingPresetName | EasingFunction`: Named preset or custom bezier curve function.
  - `extrapolateLeft?: 'clamp' | 'extend' | 'identity'` (default: `'clamp'`).
  - `extrapolateRight?: 'clamp' | 'extend' | 'identity'` (default: `'clamp'`).
- **Return Value**: `number` (interpolated output value).

#### `clampedInterpolate(options)`
Convenience helper with strict two-element tuple ranges `[start, end]`.

### B. Easing Presets & Custom Bezier (`easing.ts`)

All easing functions are pre-configured Remotion `Easing` curves:

| Preset Name | Type | Description |
|---|---|---|
| `linear` | Standard | Uniform progression without acceleration |
| `easeIn` | Classic | Standard acceleration from rest |
| `easeOut` | Classic | Standard deceleration to stop |
| `easeInOut` | Classic | Symmetric acceleration and deceleration |
| `easeInCubic` | Cubic | Steeper cubic entrance |
| `easeOutCubic` | Cubic | Smooth natural deceleration |
| `easeInOutCubic` | Cubic | Elegant S-curve |
| `easeInExpo` | Exponential | Aggressive sudden acceleration |
| `easeOutExpo` | Exponential | Rapid initial arrival settling smoothly |
| `easeInOutExpo` | Exponential | High-contrast dramatic acceleration/deceleration |
| `easeInQuart` | Quartic | Deep quartic ease-in |
| `easeOutQuart` | Quartic | Extended quartic ease-out |
| `easeInOutQuart` | Quartic | Pronounced quartic ease-in-out |
| `standard` | Signature | Decelerating curve `[0.2, 0.0, 0.0, 1.0]` |
| `emphasized` | Signature | Expressive tech curve `[0.05, 0.7, 0.1, 1.0]` |
| `decelerate` | Signature | Fast initial velocity settling cleanly `[0.0, 0.0, 0.2, 1.0]` |
| `accelerate` | Signature | Smooth departure curve `[0.4, 0.0, 1.0, 1.0]` |

#### Custom Easing Helper
```ts
import { createBezierEasing } from '../utils/animation';

const customEase = createBezierEasing(0.25, 0.1, 0.25, 1.0);
```

### C. Spring Presets & Calculation (`spring.ts`)

#### `createSpring(options)`
Calculates deterministic spring values with pre-configured physical mass, damping, and stiffness presets.

```ts
import { createSpring } from '../utils/animation';

const scale = createSpring({
  frame: currentFrame,
  fps: 30,
  delay: 10,
  preset: 'snappy',
  from: 0.8,
  to: 1.0,
});
```

- **Presets**:
  - `gentle`: `damping: 26, mass: 1.2, stiffness: 80` (subtle, elegant movements)
  - `smooth`: `damping: 20, mass: 1.0, stiffness: 120` (standard UI transitions)
  - `bouncy`: `damping: 10, mass: 0.7, stiffness: 160` (playful elastic bounce)
  - `snappy`: `damping: 15, mass: 0.6, stiffness: 200` (rapid, signature tech responsiveness)
  - `heavy`: `damping: 32, mass: 2.0, stiffness: 90` (large structural elements)
  - `stiff`: `damping: 28, mass: 0.5, stiffness: 300` (mechanical precision, clamped overshoot)
- **Boundary Safety**: Automatically returns `from` (or `to` if reverse) when `frame < delay`.

### D. Clamp and Range Utilities (`clamp.ts`)

- `clamp(value, min, max)`: Constrains a number within boundaries (handles inverted `min > max`).
- `normalizeRange(value, min, max)`: Projects number into normalized `0..1` space (safely handles `min === max`).
- `mapRange(value, inMin, inMax, outMin, outMax, clamped = true)`: Maps values between arbitrary coordinate systems.
- `getProgress(current, start, duration)`: Calculates `0..1` progression safely (handles zero or negative duration).
- `reverseProgress(progress)`: Returns clamped `1 - progress`.

## 3. Timing Utilities (`src/utils/timing/`)

### A. Frame Conversions (`frame.ts`)
- `secondsToFrames(seconds, fps)`
- `millisecondsToFrames(ms, fps)`
- `framesToSeconds(frames, fps)`
- `framesToMilliseconds(frames, fps)`
- `formatTimecode(frame, fps)`: Formats into `MM:SS:FF` SMPTE timecode.

### B. Frame Window Helpers (`duration.ts`)
- `getLocalFrame(currentFrame, startFrame)`
- `getDelayedFrame(currentFrame, delayInFrames)`
- `isFrameInRange(currentFrame, startFrame, durationInFrames)`
- `getRemainingFrames(currentFrame, startFrame, durationInFrames)`

### C. Sequence Helpers (`sequence.ts`)
- `calculateSequenceBounds(items, baseStartFrame = 0)`: Computes contiguous/delayed frame bounds for an array of items.
- `getSequenceProgress(currentFrame, sequenceItem)`: Progress for an individual sequence slice.
- `getSequenceItemIndex(currentFrame, bounds)`: Identifies active item index in a sequence.
- `calculateStagger(index, intervalFrames, baseDelay = 0)`: Stagger delay calculation.

## 4. Custom React Hooks (`src/hooks/`)

### A. `useMotion()`
Master hook combining frame context and quick pre-configured animations:

```tsx
import { useMotion } from '../hooks';

export const MyComponent = () => {
  const { frame, fps, fadeIn, slideIn, scaleIn } = useMotion();

  const opacity = fadeIn({ startFrame: 5, duration: 15 });
  const translateY = slideIn({ startFrame: 5, duration: 15, from: 30, to: 0 });
  const scale = scaleIn({ startFrame: 5, preset: 'snappy' });

  return (
    <div style={{ opacity, transform: `translateY(${translateY}px) scale(${scale})` }}>
      Content
    </div>
  );
};
```

---

### B. `useSpringProgress(options)`
Physics-driven spring hook with design presets and custom overrides:

```tsx
const springValue = useSpringProgress({
  startFrame: 10,
  preset: 'bouncy',
  from: 0,
  to: 100,
});
```

---

### C. `useStagger(options)`
Calculates staggered timelines for lists or multi-element reveals:

```tsx
const stagger = useStagger({
  itemCount: 5,
  startFrame: 10,
  staggerDelay: 4,
  itemDuration: 18,
  easing: 'easeOutCubic',
});

// Access progress per item
const firstItemProgress = stagger.getItemProgress(0);
const firstItemStatus = stagger.getItemStatus(0); // { progress, isStarted, isActive, isComplete }
```

---

### D. `useTyping(options)`
Frame-deterministic typewriter progression with blinking cursor support:

```tsx
const {
  displayedText,
  visibleCharCount,
  isComplete,
  fullTextWithCursor,
} = useTyping({
  text: 'MODERN COMMERCIAL SYSTEM',
  startFrame: 0,
  framesPerCharacter: 2,
  cursor: { blinkSpeedFrames: 14, cursorChar: '█' },
});
```

---

### E. `useFrameProgress(options)`
Normalized frame progression foundation hook:

```tsx
const {
  rawProgress,
  easedProgress,
  isStarted,
  isActive,
  isComplete,
  localFrame,
} = useFrameProgress({
  startFrame: 0,
  durationInFrames: 30,
  easing: 'standard',
});
```

## 5. Extending the Motion System

### How to Add a New Easing Preset
1. Open `src/styles/motion.ts`.
2. Add the 4 cubic bezier coordinates under `MOTION.easing`:
   ```ts
   customCurve: [0.12, 0.8, 0.32, 1.0] as const,
   ```
3. Open `src/utils/animation/easing.ts`.
4. Export the curve using `createBezierEasing`:
   ```ts
   export const customCurve = createBezierEasing(
     MOTION.easing.customCurve[0],
     MOTION.easing.customCurve[1],
     MOTION.easing.customCurve[2],
     MOTION.easing.customCurve[3]
   );
   ```
5. Register it inside `EasingPresets`.

### How to Add a New Spring Preset
1. Open `src/styles/motion.ts`.
2. Add the physical parameters under `MOTION.spring`:
   ```ts
   hyperSnappy: {
     damping: 12,
     mass: 0.4,
     stiffness: 280,
     overshootClamping: false,
   },
   ```
3. The preset name will automatically be typed and accessible across all hooks and utilities via `SpringPresetName`.
